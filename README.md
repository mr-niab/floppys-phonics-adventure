# 🐕 Floppy's Phonics Adventure

A children's phonics reading app based on the Oxford Reading Tree, Stages 1–6.

## Features

- 📚 6 reading stages aligned to Oxford Reading Tree book bands
- 🔊 Text-to-speech for every word and sound
- 🏆 Certificates on stage completion
- 📊 Parent dashboard with reading time tracking
- 🔒 No account needed — all progress saved on-device via localStorage
- 📱 Mobile-first, works offline (except Google Fonts)
- 🖥️ Responsive — sidebar nav on tablet (768px+)

## Usage

Open `index.html` directly in any modern browser. No build step required.

## Tech

- React 18 (via CDN)
- Tailwind CSS (via CDN)
- Babel Standalone (JSX in browser)
- Web Speech API
- localStorage for persistence
